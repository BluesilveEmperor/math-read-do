# Paper type taxonomy

Shared classification used by `nature-reader`, `nature-figure`, and `nature-paper2ppt`. Each skill may interpret the type differently for its own domain, but the labels and broad definitions are shared.

## Type definitions

| Paper type | Description | Sub-type guide |
|---|---|---|
| `discovery` | Discovery / mechanism papers: identifies a new phenomenon, pathway, mechanism, or biological principle. | omics discovery, spatial profiling, mutagenesis screen, imaging-based discovery, causal mechanism, molecular interaction, structural biology |
| `methods` | Methods / AI / tool / algorithm papers: introduces a new procedure, method, model, or analytical tool. | ML/AI method, software tool, experimental protocol, assay development, measurement technique, construction method |
| `resource` | Resource / dataset / atlas / omics / benchmark papers: produces a resource for the community to use. | reference dataset, benchmarking resource, atlas, cohort, repository, ontology, standards |
| `clinical` | Clinical / population / intervention studies: assesses an intervention, exposure, risk factor, or disease association in human populations. | RCT, cohort study, case-control, cross-sectional, GWAS, meta-analysis, health economics |
| `materials` | Materials / chemistry / physics / engineering papers: reports a new material, molecule, device, or physical principle. | structural characterization, property measurement, synthesis method, device performance, computational design |
| `review` | Reviews / perspectives / commentaries / meta-analyses: synthesises existing literature. | narrative review, systematic review, meta-analysis, perspective, opinion, commentary |
