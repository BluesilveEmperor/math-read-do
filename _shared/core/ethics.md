# Research and publication ethics

Applies to all nature-skills operations.

## Core principles

1. Do not fabricate data, results, or citations. Every claim in an output must trace back to a verified source.
2. Preserve the original data values in figures and tables. Do not modify scale bars, axes, or values to exaggerate or suppress patterns.
3. When in doubt, flag uncertainty, do not guess.
4. Cite every external source. Use the source's preferred citation format where available.

## Data integrity

- Extracted or copied values must match the source exactly.
- Summaries (averages, folds, p-values) must be verifiable from the numbers on the slide.

## Reproducibility

- Record all operations: extraction parameters, figure version, crop coordinates, rerun commands.
- When the source paper provides a data or code repository but no explicit license, assume it may be read-only. Do not modify or redistribute.

## AI disclosure

When content (figures, text, code) is substantially generated or modified by AI, label it in the output or in supporting metadata.
