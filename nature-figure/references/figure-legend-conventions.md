# Figure & Table Legend Conventions (Nat Commun 2025 CS/AI corpus)

Use this file when writing or auditing the legend text of a figure or table.

## Legend structure — the fixed skeleton

1. `Fig. N | ` + a bold noun-phrase overall title that names the whole figure.
2. `a / b / c …` panels, each described in present tense, telegraphic style.
3. Statistics written into the legend: sample size `n=`, error type, and test.
4. Data-availability boilerplate at the end: `Source data are provided as a Source Data file.`

## Tense

- Visual facts in present tense — `are shown as cyan sticks`, `depicts`.
- Methods/how-it-was-made in past tense — `was performed`, `was adopted from`.

## Self-containment rule

A legend must be readable away from the body text. Put colour/shape mappings,
sample size, and key numeric anchors into the legend itself.

## Table captions

Same shape: `Table N | ` + noun phrase, with detailed specs pointed to Methods.

## 中文图注要点

- 结构铁律: `图 N | 加粗名词短语总题` → `a/b/c` 现在时电报式分面 → 统计写进图注 → "Source data are provided as a Source Data file." 套语。
- 时态: 视觉事实用现在时, 制作方法用过去时。
- 自足: 颜色/形状映射、样本量、关键数值都写进图注。
