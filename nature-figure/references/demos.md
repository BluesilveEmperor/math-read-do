# Demos — Bundled figures4papers Scripts

This reference maps bundled figures4papers demo scripts to their output previews
in `assets/figures4papers/`. Use these as concrete pattern adaptation sources.

## Available demos

The `assets/figures4papers/` directory contains Python scripts adapted from
[figures4papers](https://github.com/ChenLiu-1996/figures4papers) with matching
output previews. Each script demonstrates a full figure contract → code → export
pipeline.

### How to use

1. Open the Python script that matches your figure type.
2. Replace mock data with real data while keeping the layout and palette contract.
3. Re-export with `save_pub_py()`.
